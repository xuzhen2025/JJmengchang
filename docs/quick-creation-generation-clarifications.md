# 快速创作生成区需求确认

状态：需求已完成澄清并已实现；2026-09-10 用户完整说明优先于此前冲突的约定。

## 用户已明确

- 快速创作的主要目标是快速生成用户想要的图片或视频；本轮修改首页创作区、预设及提交后的生成体验。
- 用户选择生成类型、配置参考素材、输出参数和大模型后直接生成；提交后进入参考图所示的生成模式，展示过程与结果。
- 自由创作及三个预设的生成任务统一进入全局任务队列的“快速创作”类目；点击任务后回到快速创作，自动定位对应生成记录，不跳转至 AI 视频原料。
- 生成成功不自动入库；结果先保留在快速创作记录和任务队列中，只有用户主动点击“上传资源库”并通过平台统一弹框提交后，才进入资源库。
- 生成图片的结果操作不提供“用作参考图”和“生成视频”入口，不增加由结果直接发起图片或视频续创作的流程。
- 结果操作已确认为五项：点击图片或视频预览、下载、上传资源库、重新编辑、再次生成；不增加其他编辑工具。
- 积分使用平台统一账户：提交前显示本次费用，提交时扣除；生成失败或排队取消时全额退回本次费用；不同模型的单价由原型配置示例决定。
- 生成任务统一沿用平台任务队列状态顺序“排队中 → 生成中 → 生成成功/生成失败”；排队中允许取消并退回本次积分，生成中不可取消；原型用短时模拟展示完整状态，退出页面后仍可在任务队列查看。
- 切换自由创作与预设时，手动输入内容保留；预设只在输入框中增加对应标签，不替换或清空用户文字，整体沿用当前交互。
- 生成类型切换时不保留已上传文件；手动输入文字仍保留，预设标签按当前规则保留。
- 输出视频时长由所选模型决定，不同模型提供不同范围，最高能力案例最多生成30秒；用户授权由助手设计若干模型及时长案例，无需反复确认具体样例值。
- 模型能力配置只是原型案例，正式开发须根据实际接入的大模型定义，不将样例范围表述为真实供应商能力承诺。
- 只支持图片生成和视频生成两种生成类型，不照搬参考产品的其他创作模式。
- 自由创作支持用户描述想要的内容；生成图片时可以上传参考图片，生成视频时可以上传参考图片或视频，参考素材均为可选。
- 自由视频创作允许同时上传参考图片和参考视频，共同参与本次生成，不采用二选一限制。
- 自由视频生成的参考视频最多1个，复用现有视频上传组件的格式、大小及时长校验；超出限制时提示用户并阻止提交，不自动截取或替换文件。
- 自由图片生成的输出数量复用现有“1/2/4张”选项，默认1张；产品素材预设仍固定生成4张。
- “重新编辑”回填本次结果对应的原始文字、预设标签、参考素材快照、模型和参数；“再次生成”基于当前配置创建新的任务记录，原记录和原结果始终保留。
- 上传数量已确认：自由图片生成最多7张参考图；自由视频生成最多7张参考图和1个参考视频，均可不上传；产品素材提供1至7张同一商品参考图；痛点素材、解决痛点素材各提供1份图片或视频；使用过程提供1个参考视频和1张商品图片。
- 保留三个创作预设：产品素材、痛点对比、使用过程；删除 KOC口播和剧情素材。
- 产品素材：必须上传商品参考图片，生成对应商品套图；不需要且不允许用户输入提示词。
- 商品套图固定包含4张图片：商品主图、细节特写、使用场景、卖点展示，每类1张；此规则对应产品素材预设，不等同于自由图片生成的张数设置。
- 自由图片生成的输出数量复用现有“1/2/4张”选项，默认1张；产品素材预设仍固定生成4张。
- 痛点对比：必须提供痛点素材与解决痛点素材两种素材，各自可以是图片或视频；平台自动根据内容生成视频，不需要且不允许用户输入提示词。
- 使用过程：必须提供商品使用过程参考视频及一张商品图片，通过两者生成商品使用过程视频；不显示且不允许输入提示词，用户选择输出参数及大模型后生成。不再询问商品图片是否必填或提示词是否开放。
- 产品素材对应图片生成，痛点对比和使用过程对应视频生成；用户手动切换为不匹配的生成类型时，取消对应预设选中状态。
- 各场景复用平台已有上传组件和样式，但分别保留业务所需的素材类型、用途和必填校验；不再将预设仅视为可编辑提示词模板。
- 之前确认的用户文案保护原则已明确为：手动输入内容保留，预设只在输入框中增加标签；生成类型切换时不保留已上传文件。
- 结合本平台现有业务与能力复用设计，操作尽量简单实用。
- 不纳入收藏功能；参考图中的其他功能须核对本平台业务后再决定，不能按截图全部照搬。
- 交互参考用户截图，视觉样式遵循当前平台，不直接替换成参考产品的深色界面。
- 每次仅询问一个必要问题，已明确规则不重复确认；需求收敛并确认后再实施。

## 实现记录

- `src/components/QuickCreationView.tsx` 已重做为图片/视频双模式，包含三个素材预设、素材角色校验、模型与参数、生成记录、预览、下载、资源库上传、重新编辑和再次生成。
- `src/types.ts` 增加 `QuickCreationTaskSnapshot`，生成配置随任务保存，便于任务队列回填定位。
- `src/App.tsx` 增加快速创作任务分类、5秒原型生命周期、统一积分扣退和队列点击回到快速创作记录；生成结果不自动入库。
- 参考素材选择复用 `ImageResourcePickerModal` / `VideoResourcePickerModal`，不再使用旧版 `MaterialSelector`。本地入口默认打开本地上传页签，资源库入口默认打开资源列表，均保留另一来源页签；资源库发布继续复用统一发布弹框。
- 输出参数与模型选择复用 `AnchoredPopover`，锚定按钮展开，不使用居中遮罩弹框，也不撑开表单。下方空间不足时向上避让；点击外部、再次点击按钮或按 Esc 收起。
- 输出参数即时生效，可连续修改，取消确认底栏；视频时长使用滑杆，沿用最低4秒及模型最高6/8/30秒的案例限制。模型选中后即时生效并收起。图片比例、分辨率、1/2/4张数量及产品套图固定4张规则不变。
- 自由生成最多7张参考图；视频模式可另选1个参考视频；痛点和解决素材各单选图片或视频；使用过程分别单选商品图片与使用视频。取消素材弹框不删除原素材，上传确认后才回填。
- 当前生成结果是原型模拟数据，不代表已接入真实大模型。

- 不采用“所有场景统一只接收参考图片”的方案；自由视频创作、痛点对比和使用过程均涉及视频参考。
- 不采用“所有预设只填入可编辑提示词模板”的方案；产品素材、痛点对比、使用过程均明确禁止用户输入提示词。
- 不保留 KOC口播、剧情素材两个预设。
- 不增加生成图片结果的“用作参考图”和“生成视频”入口；该排除不代表自由创作不能上传参考图片，也不取消已确认保留的重新编辑和再次生成。
- 不采用“所有模型统一只能生成1至10秒视频”的方案；时长须体现不同模型的示例能力差异，最高30秒。
