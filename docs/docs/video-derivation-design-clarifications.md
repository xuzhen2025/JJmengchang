# 视频衍生与第三方管理补齐记录

更新日期：2026-09-21。

## 已确认范围

- 成片管理的成片详情「更多」增加「衍生视频并推送」「衍生新视频」，不将这两个操作加入素材或第三方详情。
- 「衍生新视频」打开数量确认弹框，展示源视频数、每个视频衍生数量、预计总数和本次可用数量；数量必须是正整数。
- 数量上限读取「管理端 → 系统管理 → 系统设置 → 每个员工，可同时衍生视频数量上限」。正在衍生的数量占用本员工额度，完成后释放；提交时重新校验。
- 「衍生视频并推送」复用现有推送广告账户页面，仅该入口增加衍生配置。支持只衍生一个供所选账户使用，或每个不同广告账户衍生 N 个；同一账户的不同计划不重复计算衍生数量。
- 按最新确认，只保留本地衍生；云端衍生功能、未开通提示和开通入口均不展示。
- 平台名称使用「梦畅AIGC平台」，编号采用视频 ID，不采用员工 ID。
- 衍生并推送记录保留原视频关联，同时区分衍生编号和平台素材 ID。普通推送不增加衍生步骤。

## 操作记录与衍生结果

用户端「数据分析」下方新增「操作记录」，包含衍生视频记录、推送视频记录、上传文件记录、导出记录、下载记录、登录记录。超级管理员也仅查看本人的记录。

- 单独衍生完成后，不自动加入成片管理，也不发布到其他资源分区。
- 一个衍生输出对应一条衍生记录，可关联多条推送记录。「衍生视频并推送」同时生成两种记录；批量推送成功输出复用既有推送工作台，不再次衍生。
- 状态仅有：成功、失败、处理中、取消衍生、待衍生、已删除。不展示「等待」或衍生方式字段。
- 取消仅限待衍生，关联待执行推送随之取消；重试仅限失败并更新原记录；删除仅限成功输出，保留记录和原片，输出不再预览、下载或推送。混合选择不满足状态时整批拒绝。
- 支持筛选、预览、下载、批量备注、导出和查看关联推送记录；入库上传入口不在本次衍生结果页范围内。
- 是否卡审仅展示千川返回状态的演示值，未返回时显示「--」，不将审核驳回等同于卡审。
- 上传记录只在成片、素材、第三方、图片、音频、脚本成功入库后产生，不记录创作工具临时参考文件。登录记录仅在登录操作时产生，不因刷新或切换端侧重复生成。导出记录可在本次访问中下载生成文件；下载记录标记「已发起」，不代表浏览器已保存至磁盘。
- 原型衍生约 6 秒，结果复用源视频播放地址，没有真实抽帧、编码或千川接口。记录页提供固定状态案例；独立衍生和通用操作记录刷新重置，推送记录沿用现有原型存储。
- 不保证衍生内容通过广告平台重复素材或同质化审核。

## 第三方管理补齐范围

- 用户端第三方管理复用素材管理布局、详情与交互，独立资源类型和分类，不与成片或素材混放。
- 上传视频支持第三方分区；管理端分类管理和视频状态管理支持第三方，沿用现有分类占用保护及状态联动。
- 菜单权限增加「查看第三方」及对应第三方管理操作，沿用素材管理权限结构；超级管理员全开启且不可修改。
- 管理端资源管理增加第三方类型，读取与用户端相同的演示资源、上传资源、编辑结果、分类、标签和状态。
- 删除、恢复、彻底删除关联同一份第三方资源状态；回收站恢复后保持原分类，彻底删除后解除分类占用。刷新恢复原型初始演示状态。
- 既有系统设置中第三方的下载限制、自动公开设置保留；本轮未新增独立管理页面。
