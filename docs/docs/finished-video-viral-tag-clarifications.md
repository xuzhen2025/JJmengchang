# 成片爆款标记需求确认

状态：需求已确认，规则配置、成片标记与筛选联动已实现。每轮仅确认一个必要差异，已确认规则不重复询问。

## 已确认

- 范围为资源库中的成片；爆款判定标准由管理端“系统自动化标签”配置。
- 达到标准的成片自动获得爆款标记，并在成片管理卡片上以火焰图标展示。
- 火焰图标位置以用户截图为准，放在视频封面右下角，不放在卡片文字信息区。
- 标记随当前生效规则自动更新：因跨月、管理员提高门槛等原因不再达标时，自动取消，不永久保留。
- 原有“爆款视频（总消耗5w）”筛选同步改为跟随管理端规则，筛选结果与火焰标记一致。

## 修改前的实现

- 管理端已有“成片月消耗 / 总消耗达到 X 万”的配置，默认月消耗10万。
- 当前“保存设置”仅展示保存成功提示，规则尚未与成片列表共享。
- 成片列表当前有今日消耗和总消耗，未提供独立的月消耗字段，不能用今日或总消耗冒充月消耗。
- 成片列表另有写死为“总消耗5w”的爆款筛选判定，与管理端默认标准不一致；实施前需核对统一口径的涉及范围。

## 落地规则

- 不再有待确认问题。保留管理端原有的月消耗 / 总消耗选择、万元输入和“保存设置”入口。
- 只在保存成功后应用新规则，输入过程不修改生效规则。空值、零、负数或非法门槛不可保存，定位并标红输入项；存储失败不提示保存成功。
- 达到包括等于门槛，金额按分比较；月消耗按北京时间自然月取对应月份的数据，不用今日或总消耗代替。
- 页面定期更新当前统计月份，回到页面时重新核对；跨月且新月份尚未达标时取消标记。
- 火焰图标位于视频封面右下角，悬浮显示生效标准与用于判定的消耗金额；只作为状态标记，不增加新的按钮或编辑流程。
- 卡片原有选择、预览与详情点击流程保持不变；火焰在悬浮预览时也可见，并与剪切、下载、分享统计避让。
- 悬浮预览扩展到整张卡片时，火焰随预览下移至音量按钮上方；鼠标移出后恢复到封面右下角，尺寸和样式不变，始终只显示一个火焰图标。
- 图标和现有爆款筛选复用同一个判定函数；筛选选项文字展示当前标准，规则变化后仍保留所选筛选项，更新结果并回到第一页。
- 普通“消耗达到5w”等金额筛选仍保留固定金额含义，不跟随爆款规则变化。其他系统标签不在本轮范围内。
- 并行新增的“高爆款成片预设”默认使用同一爆款判定，不再硬编码总消耗5万元；其余预设功能保持不变。

## 原型数据边界

- 规则沿用现有脚本模板配置的本地存储和变更通知模式；在同一浏览器内跨页面、跨标签页联动，刷新后保留。尚未接入服务端的多用户配置与真实广告消耗接口。
- 为现有12条成片补充2026年9月的独立月消耗案例，月消耗不超过总消耗；新上传视频无投放消耗时不显示爆款标记。
- 默认月消耗10万元下，`fv5` 为月消耗12万元、总消耗15.2万元；`fv11` 为月消耗刚好10万元、总消耗18.9万元，均显示标记。
- `fv3` 为月消耗99,999.99元、总消耗12万元：月消耗10万元规则下不显示，总消耗10万元规则下显示。名称或普通标签含“爆款”的未达标案例不显示。
- 月份是数据的一部分，跨月时不会把9月演示金额重新归入新月份。
